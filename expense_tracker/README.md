# ⚛️ React + Redux Toolkit + TailwindCSS Boilerplate

A modern and reusable **React 19** boilerplate built with:

- ⚡ [Vite 6](https://vitejs.dev)
- 🧠 [Redux Toolkit](https://redux-toolkit.js.org)
- 🎨 [TailwindCSS 4](https://tailwindcss.com)
- 🔁 [React Router 7](https://reactrouter.com)
- ⚙️ Optimized file structure with async thunk & DevTools ready setup

---

## 🚀 Features

- ✅ Ready Redux Toolkit store with DevTools enabled
- ✅ Example `createAsyncThunk` (API fetching)
- ✅ Pre-configured TailwindCSS v4
- ✅ Path aliasing (`@`) for cleaner imports
- ✅ Organized folder structure for scalable projects
- ✅ React Router 7 integrated

---

## 📂 Folder Structure

src/
├── app/ # Redux store setup
├── components/ # Shared UI components
├── features/ # Redux slices + feature components
├── hooks/ # Custom Redux hooks
├── layouts/ # Main layout & Header
├── pages/ # Page-level components
├── styles/ # TailwindCSS styles
├── utils/ # Helper & API files
├── App.jsx
├── main.jsx
└── router.jsx

---

## ⚙️ Installation & Setup

# 1️⃣ Install dependencies

npm install

# 2️⃣ Start development server

npm run dev

# 3️⃣ Build for production

npm run build

# 4️⃣ Preview production build

npm run preview
